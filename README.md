# stockfish-arm-bench

Benchmarks official Stockfish releases on a GitHub-hosted arm64 runner:
plain `armv8` vs `armv8-dotprod` builds, with 1, 2 and 4 threads, and the
time each build needs to reach a fixed search depth.

Stockfish is free software under the GNU GPL v3: https://github.com/official-stockfish/Stockfish
This repository only builds and runs the unmodified upstream sources.
